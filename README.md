# Minimal "Hero of The Kingdom" Clone in React

Collect mushrooms forever ;)

## Development

Install dependencies with `npm install`, then run:

- `npm start` or `npm run dev` to start the Vite development server at
  [http://localhost:3000](http://localhost:3000).
- `npm run build` to create a production build in `build/`.
- `npm run preview` to serve the production build locally.
- `npm test` to run Vitest in watch mode, or `npm run test:run` for a one-time
  test run.
